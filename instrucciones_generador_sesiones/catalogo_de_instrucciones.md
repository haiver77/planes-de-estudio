# Catálogo de instrucciones para generar sesiones

Usa este catálogo para elegir las instrucciones según el **objetivo principal de aprendizaje**. Si un elemento parece encajar en varias categorías, elige la instrucción más específica para la función que se quiere practicar.

## Selección rápida

| Necesitas practicar… | Usa este archivo |
|---|---|
| Un verbo, sus conjugaciones y su uso repetido en frases sencillas | [aprendizaje_verbos.md](./aprendizaje_verbos.md) |
| Un sustantivo, objeto o concepto léxico, con artículos, número o contabilidad cuando corresponda | [aprendizaje_sustantivos.md](./aprendizaje_sustantivos.md) |
| Un adjetivo, sus sentidos, concordancia, posición o función en la frase | [aprendizaje_adjetivos.md](./aprendizaje_adjetivos.md) |
| Un adverbio o locución adverbial: modo, tiempo, frecuencia, lugar, grado, negación, foco u otra función adverbial | [aprendizaje_adverbios.md](./aprendizaje_adverbios.md) |
| Un determinante: artículo, demostrativo, posesivo, cuantificador, numeral, interrogativo, exclamativo o distributivo | [aprendizaje_determinantes.md](./aprendizaje_determinantes.md) |
| Una preposición o locución preposicional y la relación que expresa —por ejemplo, lugar, dirección, tiempo, causa o compañía— | [aprendizaje_preposiciones.md](./aprendizaje_preposiciones.md) |
| Una conjunción o construcción conjuntiva y la relación lógica o gramatical que establece entre ideas | [aprendizaje_conjunciones.md](./aprendizaje_conjunciones.md) |
| Una expresión fija, phrasal verb, patrón gramatical, expresión de cantidad u otro objetivo formulado como una frase o estructura completa | [aprendizaje_frases_y_expresiones.md](./aprendizaje_frases_y_expresiones.md) |

## Criterios para resolver solapamientos

- **La categoría gramatical determina la elección.** Una palabra que conecta ideas puede ser un adverbio conector o una conjunción: usa las instrucciones de su categoría y función, no solo su papel general de “conector”.
- **Preposición frente a expresión fija:** si se enseña una relación preposicional y su complemento, usa `aprendizaje_preposiciones.md`. Si se aprende una expresión como una unidad cuyo sentido no se obtiene de sus partes, usa `aprendizaje_frases_y_expresiones.md`.
- **Verbo frente a phrasal verb:** para practicar un verbo y sus conjugaciones, usa `aprendizaje_verbos.md`. Para aprender un phrasal verb como unidad, usa `aprendizaje_frases_y_expresiones.md`.
- **Palabra frente a estructura:** si el objetivo es un sustantivo u otra categoría léxica, usa su archivo específico. Si el objetivo es un patrón o una expresión completa, usa `aprendizaje_frases_y_expresiones.md`.
- **Sentidos diferentes:** cuando un objetivo tenga varios sentidos o funciones, las instrucciones especializadas suelen recomendar separar la práctica por sentido, salvo que se solicite compararlos.

## Alcance común

Los archivos especializados están diseñados para generar CSV de aprendizaje y priorizan la repetición del objetivo, ejemplos naturales, progresión gradual y traducciones equivalentes. Consulta el archivo seleccionado para sus parámetros, estructura de sesión, reglas gramaticales y revisión final específicas; no asumas que los detalles de una categoría se aplican sin cambios a las demás.
